# feecalc — 医疗费用报销预估平台

单文件医保费用预估工具（脑出血·开颅 / 白血病·化疗 / 移植等场景），面向保险顾问展业使用。

## 功能

- **费用测算**：按参保类型（东莞/江门职工·居民医保、无医保）× 就医情形（市内 / 市外转诊 / 市外未转诊），输出总费用、医保报销、自费三卡 + 透明瀑布明细
- **政策引擎**：内置东莞/江门 2025–2026 年度现行待遇参数（起付线、分段比例、大病保险、东莞金卡大额补助），参数经专家团三角色核验（34/36 通过）
- **药品耗材**：按方案自动切换常用药表，自费/自购项单独小计
- **朋友圈海报**：6 套 Canvas 模板，一键生成 1080×1350 海报；移动端三级保存策略（系统分享存相册 → 下载 → 长按保存）
- **对比面板**：同一病情三种就医情形自费差异对比
